# Henry Norwest — history project

This folder is ready to publish as a GitHub Pages project site. It contains the complete static website, its images and documents, and an initialized local Git repository.

1. Download and install GitHub Desktop, then sign in to the GitHub account that will own the site.
2. Extract this ZIP. In GitHub Desktop choose **File → Add Local Repository**, select the extracted `henry-norwest-github-pages` folder, and click **Add Repository**.
3. In **Changes**, enter a summary such as `Add Henry Norwest history website`, then click **Commit to main**.
4. Click **Publish repository**. Name it `henry-norwest`, choose your personal account, and **uncheck Keep this code private**. Click **Publish Repository**.
5. Open the repository in a browser. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and click **Save**.
6. GitHub will show the published address. For a repository named `henry-norwest`, it will normally be `https://YOUR-USERNAME.github.io/henry-norwest/`.

The site uses relative asset paths and hash navigation, so it works under a project path without editing its links. Keep the `assets` and `documents` folders together with `index.html`.
